# Remote-Control Layer

This directory is reserved for future VintaNetGS remote-control work.

Remote control must wait until serial transport and packet communication are proven. VintaNetGS-specific remote control of a cooperating peer is separate from any investigation into controlling arbitrary GS/OS applications.

Not implemented in Phase 1:

- Keyboard injection
- Application launch control
- Remote screen state
- Arbitrary GS/OS application control
